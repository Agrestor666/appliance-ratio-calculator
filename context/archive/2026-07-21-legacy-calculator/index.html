    Rigging calculator – help
    How to pick items, use buttons, and send the result.
    What this window does
    This window lets you select rigging elements and calculate their total weight. Confirmed items go to the log, and the log total can be sent back to the main Rigging Weight field.
    Selecting rows
    - Use the Pick checkbox, or double left-click a row to toggle Pick.
    - Edit Qty and (where available) Len (m) using the input or the − / + buttons (step = 1).
    Buttons
    - Confirm & add to log: adds picked rows to the log and clears the current selection. (Press Enter to do the same.)
    - Clear selection: unpicks rows in the current selection only.
    - Clear the log: removes all log entries and resets the log total.
    - Send sum to Rigging Weight: writes the log total (Te) into the main Rigging Weight field and recalculates results.
    Notes
    The catalog is read-only. Only the log total is sent to the main calculator when you click Send sum to Rigging Weight.
